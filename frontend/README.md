# StudyVault Frontend

React 19 + Vite single-page app for StudyVault. See the [root README](../README.md) for full setup.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build to dist/
npm run lint
```

The API base URL is set in [`src/api/client.js`](src/api/client.js) (default `http://127.0.0.1:8000`).
